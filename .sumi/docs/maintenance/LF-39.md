# LF-39: Isolate CLI skill installation tests

The skill installation tests in `tests/test_cli.py` depend on the checkout containing
`factory-design` and `factory-workflow`. Renaming those bundled skills breaks tests
that are intended to verify installation behavior, not the skill catalog.

Refactor only these tests to install temporary skill fixtures through a patched
`cli.TOOLS`. Keep repeat-install, conflict preservation, and user/project scope
coverage. Isolate home and legacy Codex paths from the developer environment.
Production behavior and the bundled skill catalog are outside this maintenance scope.

Completed the fixture refactor. Both installation tests now use temporary sources,
and the project-scope check observes the same patched home used by the installer.
Validation: all 8 tests passed with
`python3 -m unittest discover -s tests -p test_cli.py -v`; `git diff --check` passed.
